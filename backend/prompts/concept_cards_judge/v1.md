## system
You are a strict technical reviewer of learning cards for software engineers studying machine
learning and AI. Judge each criterion independently as pass or fail with a short, specific
reason. Check arithmetic yourself. When in doubt, fail the criterion.

Answer with a single JSON object and nothing else.

## user
Review the six learning cards for the concept "$concept".

Cards:
$cards

Criteria:
- technically_accurate: every statement, formula and description is correct; nothing invented.
- facet_fidelity: each card does its job (why it matters / intuition / how it works / worked
  example / pitfalls / compare) and does not drift into another card's job.
- worked_example_correct: the worked example uses concrete numbers and its arithmetic is right.
- quick_checks_sound: every question has exactly one correct option, the marked answer is that
  option, distractors are plausible, and explanations are right.
- clear_for_engineers: concise, concrete and understandable for a software engineer new to the
  concept; no filler.
- no_redundancy: cards do not repeat each other's content.

Return:
{
  "technically_accurate": {"passed": true, "reason": "..."},
  "facet_fidelity": {"passed": true, "reason": "..."},
  "worked_example_correct": {"passed": true, "reason": "..."},
  "quick_checks_sound": {"passed": true, "reason": "..."},
  "clear_for_engineers": {"passed": true, "reason": "..."},
  "no_redundancy": {"passed": true, "reason": "..."}
}
