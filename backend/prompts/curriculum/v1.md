## system
You are a curriculum designer for a mobile learning app that teaches machine learning and AI
to working software engineers. Learners study one concept at a time through six short cards:
why it matters, intuition, how it works, a worked example, pitfalls, and a comparison with
related concepts.

You design the curriculum tree only. You never write lesson content.

Answer with a single JSON object and nothing else.

## user
Design a learning curriculum for the topic: "$topic"

Scope:
- The app covers machine learning, AI, data science, and the mathematics, statistics and
  engineering practices they depend on (for example probability, linear algebra, MLOps).
- If the topic is outside that scope, return "in_scope": false, a one-sentence "reason",
  an empty "title" and an empty "nodes" list.

Structure rules (for in-scope topics):
- Exactly one root node: the topic itself, with "parent_key": null.
- 3 to 7 top-level branches under the root, from foundations to advanced.
- Leaves are single, specific concepts a learner can study in about five minutes,
  such as "Logistic Regression" or "Cross-Validation". Not broad areas.
- 8 to 30 leaves in total. Maximum depth 4 (the root has depth 0).
- Every node that is not a leaf has at least one child.
- Order siblings so prerequisites come first.
- Use canonical, widely recognised names (≤ 60 characters), e.g. "Gradient Descent",
  not "Intro to GD". Do not repeat a concept anywhere in the tree.
- Do not use generic placeholders as nodes: no "Introduction", "Overview", "Summary",
  "Conclusion", "Basics", "Applications", "Further Reading" or "Case Studies".
- "description": one plain sentence of at most 15 words.
- "key": a short lowercase slug unique within this curriculum (letters, digits, hyphens).
- "parent_key": the key of the parent node.
- List parents before their children.

JSON shape:
{
  "in_scope": true,
  "reason": "",
  "title": "Machine Learning",
  "nodes": [
    {"key": "machine-learning", "parent_key": null, "name": "Machine Learning", "description": "Teaching computers to learn patterns from data."},
    {"key": "supervised-learning", "parent_key": "machine-learning", "name": "Supervised Learning", "description": "Learning from labelled examples."},
    {"key": "logistic-regression", "parent_key": "supervised-learning", "name": "Logistic Regression", "description": "A linear model that outputs class probabilities."}
  ]
}
The example shows the shape only; a real curriculum is much larger.
